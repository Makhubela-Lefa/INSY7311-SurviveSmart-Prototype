## Project Overview
SurviveSmart is a mobile budgeting and financial habit tracking application designed for university students.

## Main Features
- Expense logging
- Budget tracking
- Savings goals
- Habit tracker
- Spending alerts
- Weekly reports
- Financial tips
- Profile setup
- Settings management
